# Addition Without Regrouping
### Grade 2 Mathematics · Intellia SG

A complete React 18 + Vite educational app teaching **Addition within 100 without regrouping** through a 5-phase gamified learning journey.

---

## 🚀 Quick Start

```bash
npm install
npm run dev      # → http://localhost:5173
```

### Production Build
```bash
npm run build    # outputs to /dist
npm run preview  # preview the build
```

## 🎯 5-Phase Learning Journey

| Phase | Description |
|-------|-------------|
| **Wonder** | Emma's sticker problem — sparks curiosity |
| **Story** | Wei Ming at Pasar Malam — 4 illustrated panels |
| **Simulate** | 3 interactive stations (Blocks, Place Value, Column) |
| **Play** | 10 worlds × 8 questions with full gamification |

## 🔊 Audio Setup (Optional)

The app runs **without audio** by default. To enable narration:

### 1. Generate audio files
```bash
export ELEVENLABS_API_KEY=your_api_key_here
node scripts/generate_audio.js
```
This generates `.mp3` files in `public/assets/audio/` and updates `src/utils/audioMap.js`.

### 2. Clean orphaned files (after script changes)
```bash
node scripts/clean_audio.js
```

### Audio Architecture
- **Voice:** Alice (`Xb7hH8MSUJpSbSDYk0k2`) · ElevenLabs Multilingual v2
- **No Web Speech API fallback** — silent skip if audio unavailable
- **Preloading:** segment N+1 fetched while N plays (zero-gap narration)
- **Dynamic generation:** phrases not in `audioMap` generated on-the-fly if API key set

## 🎮 Gamification

| Feature | Details |
|---------|---------|
| XP | +10 correct, +5 with hint, +2/+5 streak bonus |
| Lives | 3 hearts per world, lost on wrong answers |
| Streak | 🔥 counter resets on wrong answer |
| Stars | 0–3 per world (≥90% = 3★, ≥70% = 2★, ≥50% = 1★) |
| Worlds | 10 worlds, unlock sequentially |
| Badges | 8 achievement badges |

## 📋 Question Validation

All 100 questions satisfy the **no-regrouping constraint**:
- Ones digits sum ≤ 9
- Tens digits sum ≤ 9
- No carrying required
